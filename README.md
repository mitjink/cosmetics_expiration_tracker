# Сервис контроля сроков использования косметики

Консольное приложение для учёта косметических средств и контроля сроков их использования после вскрытия упаковки.

## Назначение

Приложение помогает пользователям отслеживать сроки годности и периоды использования косметических средств после вскрытия упаковки. Сервис решает проблему просроченной и испортившейся косметики, которая может навредить коже, и избавляет от необходимости запоминать даты вскрытия каждого тюбика и баночки.

## Целевая аудитория

- Люди, активно ухаживающие за собой и использующие много косметических средств одновременно.
- Визажисты, стилисты и сотрудники бьюти-индустрии, работающие с большим ассортиментом продукции.
- Владельцы косметических запасов, желающие оптимизировать расход и не выбрасывать зря продукты.
- Пользователи, заботящиеся о безопасности и гигиене при использовании косметики.

## Предметная область

Предметная область — учёт косметических средств и контроль сроков их использования. Каждый продукт имеет срок годности до вскрытия и период использования после вскрытия (например, 6M, 12M, 24M, обозначаемые на упаковке значком открытой баночки). После вскрытия продукта отсчёт идёт по второму сроку, и по его истечении средство считается непригодным. Сервис хранит информацию о продуктах, датах вскрытия и напоминает о приближении окончания срока использования.

## Основные сущности

### Cosmetic — косметическое средство

Объект `Cosmetic` представляет косметическое средство.

Основные атрибуты:

- `id` — уникальный идентификатор;
- `name` — название;
- `brand` — бренд;
- `expiry` — срок годности до вскрытия;
- `months` — срок использования после вскрытия;
- `opened` — дата вскрытия (или `None`).

Основные методы:

- `is_opened()` — проверка, вскрыто ли средство;
- `is_expired_before_opening()` — проверка, истёк ли срок годности до вскрытия;
- `open()` — отметить средство как вскрытое;
- `get_deadline()` — дата окончания срока использования;
- `get_days_left()` — сколько дней осталось;
- `get_status()` — текстовый статус;
- `to_dict()` и `from_dict()` — преобразование в JSON и обратно;
- `__str__()` — строковое представление.

### User — пользователь

Объект `User` представляет пользователя системы.

Основные атрибуты:

- `id` — уникальный идентификатор;
- `name` — имя;
- `email` — адрес электронной почты.

Основные методы:

- `to_dict()` и `from_dict()` — преобразование в JSON и обратно;
- `__str__()` — строковое представление.

### UsageRecord — запись об использовании

Объект `UsageRecord` связывает средство и пользователя и фиксирует дату вскрытия.

Основные атрибуты:

- `id` — уникальный идентификатор;
- `cosmetic` — объект `Cosmetic`;
- `user` — объект `User`;
- `opened_date` — дата вскрытия;
- `is_cancelled` — признак отмены.

Основные методы:

- `cancel()` — отменить запись;
- `to_dict()` и `from_dict()` — преобразование в JSON и обратно;
- `__str__()` — строковое представление.

## Взаимодействие объектов

Объект `UsageRecord` связывает объект `Cosmetic` и объект `User`. Это позволяет получать данные связанных объектов напрямую: `record.cosmetic.brand`, `record.user.name`. При сохранении в JSON хранятся только идентификаторы `cosmetic_id` и `user_id`, а при загрузке выполняется поиск соответствующих объектов.

## Возможности

- Добавление косметических средств.
- Добавление пользователей.
- Отметка вскрытия средства с созданием записи об использовании.
- Отмена записи об использовании.
- Просмотр списка средств с отображением статуса.
- Просмотр списка пользователей.
- Просмотр списка записей об использовании.
- Напоминания о средствах, срок использования которых подходит к концу или уже истёк.
- Сохранение и загрузка данных в формате JSON.

## Формат данных

Данные хранятся в JSON-файлах в каталоге `data/`. При загрузке данные преобразуются в объекты классов `Cosmetic`, `User` и `UsageRecord`, а при сохранении — обратно в JSON.

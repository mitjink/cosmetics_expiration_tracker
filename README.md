# Сервис контроля сроков использования косметики

Консольное приложение для учёта косметических средств и контроля сроков их использования после вскрытия упаковки.

## Назначение

Приложение помогает пользователям отслеживать сроки годности и периоды использования косметических средств после вскрытия упаковки. Сервис решает проблему просроченной и испортившейся косметики, которая может навредить коже, и избавляет от необходимости запоминать даты вскрытия каждого тюбика и баночки.

## Целевая аудитория

- Люди, активно ухаживающие за собой и использующие много косметических средств одновременно.
- Визажисты, стилисты и сотрудники бьюти-индустрии, работающие с большим ассортиментом продукции.
- Владельцы косметических запасов, желающие оптимизировать расход и не выбрасывать зря продукты.
- Пользователи, заботящиеся о безопасности и гигиене при использовании косметики.

## Предметная область

Предметная область — учёт косметических средств и контроль сроков их использования. Каждый продукт имеет срок годности до вскрытия и период использования после вскрытия (например, 6M, 12M, 24M, обозначаемые на упаковке значком открытой баночки). После вскрытия продукта отсчёт идёт по второму сроку, и по его истечении средство считается непригодным. Сервис хранит информацию о продуктах, датах вскрытия и напоминает о приближении окончания срока использования.

## Основные сущности

- Косметическое средство — продукт с названием, брендом, сроком годности до вскрытия и сроком использования после вскрытия.
- Дата вскрытия — момент, с которого начинается отсчёт срока использования.
- Статус средства — текстовое состояние: «не вскрыто», «просрочено до вскрытия», «ок», «скоро истекает», «ПРОСРОЧЕНО».

## Возможности

- Добавление косметических средств с указанием срока годности и срока использования после вскрытия.
- Отметка даты вскрытия продукта и автоматический расчёт даты окончания срока использования.
- Просмотр списка средств с отображением статуса.
- Напоминания о средствах, срок использования которых подходит к концу или уже истёк.
- Поиск средства по подстроке в названии или бренде.
- Сортировка списка средств по названию.
- Статистика по количеству средств в каждом статусе.
- Сохранение и загрузка данных в формате JSON.

## Структура проекта

- `main.py` — точка входа, организация меню и вызов функций проекта.
- `cosmetics.py` — логика предметной области: добавление, вскрытие, статусы, поиск, сортировка, статистика.
- `storage.py` — чтение и запись JSON-файла через контекстный менеджер `with`, обработка ошибок файлов.
- `utils.py` — функции безопасного ввода с обработкой исключений.
- `data/` — каталог для JSON-файлов данных.
- `tests/` — автоматизированные тесты pytest.

## Формат данных

Данные хранятся в файле `data/cosmetics.json` в виде списка словарей:

```json
[
  {
    "name": "Крем для лица",
    "brand": "Example",
    "expiry": "2026-12-31",
    "months": 6,
    "opened": "2026-09-27"
  }
]
```
Поле opened имеет значение null, если средство ещё не вскрыто.
